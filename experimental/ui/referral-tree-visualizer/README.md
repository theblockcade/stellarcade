# Referral Tree Visualizer

A collapsible hierarchical tree view of a player's multi-tier referral network — tier-1 and tier-2 invitees, accumulated commission earnings, and active/inactive status.

## Features

- **Hierarchical Tree Layout**: The current user is the root node; direct invitees branch below, with their own invitees nested one level further
- **Expandable / Collapsible Nodes**: Any node with children can be toggled via a chevron button; the root starts expanded, everything else starts collapsed
- **Node Summary Chips**: Each node shows the invitee's username, truncated address, total wagers generated, and referral rewards earned, plus an active/inactive status dot
- **Search Filtering**: Live filtering by username or address substring; a node whose *descendant* matches is auto-expanded so the match stays visible even if its ancestor was collapsed
- **Empty State**: A "Share your referral link to build your team" invite card when the root has no invitees yet
- **Deep Trees**: Wraps by default; a horizontal-scroll container is the fallback for rows that still overflow at a deep indent

## Installation

```bash
# Copy the component to your project
cp -r experimental/ui/referral-tree-visualizer /path/to/your/components/
```

## Usage

```tsx
import { ReferralTreeVisualizer } from './referral-tree-visualizer/ReferralTreeVisualizer';
import type { ReferralNode } from './referral-tree-visualizer/types';

function ReferralPage() {
  const treeData: ReferralNode = {
    address: 'G...YOU',
    username: 'you',
    isActive: true,
    totalWagers: 5000,
    rewardsEarned: 250,
    children: [
      {
        address: 'G...ALICE',
        username: 'alice',
        isActive: true,
        totalWagers: 2000,
        rewardsEarned: 100,
        children: [
          {
            address: 'G...DIANA',
            username: 'diana',
            isActive: false,
            totalWagers: 300,
            rewardsEarned: 15,
            children: [],
          },
        ],
      },
    ],
  };

  return (
    <ReferralTreeVisualizer
      treeData={treeData}
      onCopyInviteLink={() => navigator.clipboard.writeText('https://example.com/invite/you')}
      onInspectUser={(address) => console.log('Inspect', address)}
    />
  );
}
```

## Props

### `ReferralTreeVisualizer`

| Prop | Type | Description |
|---|---|---|
| `treeData` | `ReferralNode` | The root node (the current user), with nested `children` for tier-1/tier-2 invitees |
| `onCopyInviteLink` | `() => void` | Called when "Copy Invite Link" is clicked in the empty state |
| `onInspectUser` | `(address: string) => void?` | Called with a node's address when its identity button is clicked |
| `className` | `string?` | Additional class name on the root element |
| `testId` | `string?` | Optional root `data-testid` override (default `referral-tree-visualizer`) |

### `ReferralNode`

| Field | Type | Description |
|---|---|---|
| `address` | `string` | Wallet address or user id |
| `username` | `string` | Display handle |
| `isActive` | `boolean` | Wagered in the last 30 days |
| `totalWagers` | `number` | Total wagers generated by this invitee |
| `rewardsEarned` | `number` | Referral rewards earned from this invitee's activity |
| `children` | `ReferralNode[]` | This node's own invitees (empty for a leaf) |
